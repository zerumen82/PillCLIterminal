## Pasos y contratos

1. `src/files/`, `tests/files_real.rs`: listar, buscar, leer bytes/versiones, crear sin sobrescribir y editar coincidencia única con SHA-256 esperado. Preservar BOM/CRLF fuera del cambio. Rutas relativas bajo raíz canónica; rechazar enlaces/reparse/hardlinks múltiples, nombres especiales Windows y áreas de control del ejecutor. Límites en FilesConfig.
2. Windows: pinar directorios sin compartir borrado y abrir original con READ/DELETE y compartición de lectura. Preparar temporal completo; mover original por handle a reserva privada y publicar temporal por handle sin sobrescribir. Verificar con el mismo handle. Se conserva backup y evidencia. Entre renames existe una ventana sin destino: colisión produce rollback sin sobrescribir o resultado parcial con backup conservado; no se promete transacción atómica ni restauración encima de cambios ajenos. Limitar reservas conservadas y fallar al agotarlas.
3. `src/providers/ollama/`, `src/tools/`, `src/session/`: anunciar esquemas de herramientas nativas, acumular llamadas únicamente hasta final válido, validar argumentos tipados, ejecutar mediante un único coordinador y devolver resultado vinculado al modelo. Texto del modelo no prueba acciones. Herramientas desconocidas y fragmentos incompletos no tienen efectos. Conservar evidencias de efectos aunque una inferencia posterior falle o se cancele.
4. `src/tools/commands.rs`, `tests/commands_real.rs`: configuración propone programa absoluto, argumentos, directorio y scripts observados. Concesión privada vinculada a raíz, definición y hashes; cambiar programa/script invalida autorización. UI muestra propuesta completa y concede solo tras selección explícita del usuario. Ejecutar sin shell implícito, con salida acotada, código, timeout y cancelación del árbol hijo propio mediante Job Object Windows. Crear suspendido, asignar job y reanudar, sin ventanas visibles. No constituye sandbox del código ejecutado.
5. `src/agents/`: conversaciones separadas para coordinador/explorador/implementador/tester/reviewer, con permisos de herramientas por rol y límites de pasos/inferencia. No confundir estados generados por el modelo con PASS real de comandos o aplicación de archivos. Serializar inferencia y efectos; propagar fallos y límites. La prueba real debe registrar identidad de cada rol y resultados de herramientas.
6. `src/ui/`, `src/config/`, `config/defaults.json`, README y bitácora: herramientas/operaciones visibles, cambios y resultados reales; protección del pegado antes de acciones con efectos, cancelación y restauración. Modelo sigue explícito; no descargar ni cambiar automáticamente. Historial persistente completo, MCP y liberación conservan sus etapas siguientes; no se anuncian como ya disponibles.
