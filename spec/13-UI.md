# UI compacta y acciones explícitas · 2026-10-27

Implementación autorizada por «arréglalo todo» sobre la revisión de usabilidad
y por U01/U02/U03/U04/U10/U12 de `10-USABILIDAD-FIABILIDAD-INSTALACION.md`.
No añade dependencias ni selecciona modelo principal.

- Esc cierra selector de modelos/permisos/detalles y conserva la selección
  efectiva; no concede ni ejecuta al cerrar. El pie muestra acciones reales.
- Ctrl+Enter confirma liberación y las decisiones humanas; Enter muestra
  explicación o detalle y nunca confirma descarga/concesión.
- La cabecera compacta mantiene cápsula, proyecto, modo, modelo y actividad.
  `/status` muestra rutas, digest, reserva conservadora, configuración y
  selección de sesión. El dibujo completo se conserva como opción.
- Las filas de permisos describen operación, origen, destino y estado;
  huellas y argumentos completos permanecen accesibles en detalle legible.
- `/ask` selecciona consulta de solo lectura, `/edit` edición con herramientas,
  `/chat` conserva compatibilidad y `/task` exige pruebas/revisión. Cambiar
  etiqueta de modo no concede permisos ni amplía el alcance.
- `/changes` muestra resultados observados y cambios completos dentro de la
  retención configurada, incluido motivo de fallo y respaldo. Una vista no
  convierte propuesta o fallo en cambio aplicado.
- `/recover` muestra la evidencia estructurada que expone el backend; la
  revisión humana usa la huella actual, Ctrl+Enter y resultado durable. No
  reproduce escrituras ni elimina el bloqueo de operaciones no revisadas.
- `/undo` solo se anuncia con backend real y confirma una propuesta concreta
  con SHA posterior y respaldo; rechaza destinos cambiados.
- El historial de pantalla tiene cota de entradas y bytes, con aviso de
  retención. Los errores de guardado se hacen visibles y persistentes.
- PgUp/PgDn usa el área de historial realmente visible. La ventana vertical
  conserva cursor, fila seleccionada, avisos y pie a 73×21.
- El ancho representa latinos como una celda, marcas combinantes/ZWJ como
  cero y secuencias amplias de forma conservadora. Se comprueban acentos,
  marcas, familia ZWJ y bandera; no se promete toda fuente/terminal Unicode.
- Se reutiliza el ajuste del historial y se actualizan únicamente filas que
  cambian. Durante streaming se limita render con configuración; entrada,
  cancelación y resize siguen atendidos. Las mediciones antes/después serán
  evidencia real, no ahorro inferido por inspección.

Pruebas: regresiones del modelo de UI y render, consola real con metadatos
locales en proyecto temporal y posterior repetición de las integraciones
afectadas. Formato/lint/build, tester y reviewer se ejecutan al integrar; este
documento no afirma que hayan pasado sobre las nuevas fuentes.
